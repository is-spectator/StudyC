## 复刻与 K12 替换的范围

- 原版配色、字体、页面框架、侧栏、圆角、按钮形态、插画与各截图初始状态作为依据。原始素材 URL 见 `public/assets/studyfetch/sources.json`，设计 token 与公开资源证据见 `source-evidence.md`。
- 身份、学习阶段与学习内容限定为 K12；资料标题根据小学、初中、高中及语数英主题选择。付费权益与题库页面中的护理考试内容改成 K12 同步题库。题库保留原版头图、交互展示和三列入口结构，替换为小学、初中、高中；不沿用原版的专家审核宣称或题目数量。
- 付费学生书桌插画来自保存的原站 `0nmjrzis1jarl.js` 中 `Student studying at a desk` 对应的完整内联 SVG。价格来自保存的 `3nd9aoqx3682s.js`：Premium 月付 $19、年付 $96；Max 月付 $50、年付 $225。显示价格仅用于参考页还原，支付弹窗明确说明不下单、不收费。
- Mini Apps 保留原画廊的布局、分段标签、横向卡片和渐变缩略图结构；社区作者、点赞数和投票换成可用的 K12 示例、收藏与本地快捷入口，不伪造社区活动。
- 街机画廊改为可玩的 K12 知识配对示例，保留搜索、排序与创建流程。创建首步的游戏预览图仅作原版视觉参考；实际游戏没有跑酷、竞速或 3D 引擎。
- 阅读页根据文章首屏截图调整长文布局；正文仍为内置 K12 示例，不代表原站文章内容已完整复制。
- 设置页保留分类标签、头像、手机卡片与资料表单结构，替换为本地示例账号；头像、名字、用户名与年级可以保存。原站截图中的账号信息不用于应用默认值。
- 首页纸张缩略图为 HTML 文本，Sparky 二维码为本地生成并指向原站官网，不等同于原站短信服务二维码。

## 当前源码中的本地行为

| 页面组 | 当前可用行为 | 主要边界 |
| --- | --- | --- |
| 引导与学习空间 | 选择学习阶段、建立学习集、搜索/排序/改名、文件夹归属、按阶段查看示例资料、专注计时 | 资料处理流程使用本地输入与内置示例，不调用生成服务 |
| 学习计划、资料、笔记、日历 | 标记学习计划完成、TXT/Markdown 导入、笔记编辑、资料搜索、日/周/月日历、安排增删改 | 无 PDF/Word 解析、云端文件库、外部日历同步或推送 |
| 闪卡、测验与题库 | 创建/复习卡片；使用内置题目进行测验、考试、判分与解析；题库按阶段、学科和关键词选择练习 | 题目是有限示例，不是完整教材题库；自动从文件出题尚未接入 |
| 聊天与辅导 | 输入聊天内容、浏览工具建议、逐步查看预设 K12 题目、提示与解析 | 无实时 AI 回复或语音辅导；会话不能视为云端历史记录 |
| 课堂录音与音频回顾 | 获得麦克风授权后录音、回放和下载；手动课堂笔记；创建朗读配置、调速、浏览器语音朗读 | 无 AI 转写或 AI 音频生成；录音只在当前页面内存，离开或刷新后不保留，需先下载 |
| 街机与 Mini Apps | 搜索/排序知识配对示例、4 组配对反馈、创建游戏配置；收藏应用与保存学习工具快捷入口 | 无社区服务、PDF 自动转游戏、AI 应用生成或 3D 游戏引擎；游戏配置与朗读配置各保存最近一份 |
| 作业与视频讲解 | 保存作业文本、统计字符/段落/标点、图片本地预览；保存讲解提纲、查看内置讲解、下载文本 | 无作业正确性评分、OCR 或视频生成；图片预览不等同于文字识别 |
| 设置与会员方案 | 保存头像/名字/用户名/年级、查看本地用量、导出本项目已保存的学习数据、选择参考价格方案 | 账号、订阅、移动端登录、短信、Canvas、Mac 应用和支付未接入；选方案不下单或收费 |

本地记录使用当前浏览器的 localStorage。学习集、笔记、卡片记录、练习成绩、日历、草稿与收藏不自动同步到其他设备；清除站点数据会删除这些记录。设置页可导出本项目三个存储命名空间中的已存记录；导出不包含录音 Blob、图片预览或尚未保存的页面状态，也未实现备份导入。

## 证据与验证边界

- 表中的截图证明已观察到对应画面。具体实现使用 React 组件与本地交互，截图覆盖不等于原站全部页面或全部状态已经实现。
- 有截图依据的首屏、空态和创建第一步，与后续本地交互分别处理。阅读首屏之后的长文内容、具体卡片/题目、游戏进行中、生成结果、后续设置标签、错误状态、其他弹窗、移动端与深色主题没有完整的逐状态原站截图依据。
- 已采图页面尚未进行全量自动像素差分，因此不宣称全站逐页或每个像素完全相同。K12 题库、社区示例内容和未连接服务的说明属于明确的本地适配。
- 本清单根据当前路由与源码整理，不把静态界面中的原版功能名视为服务已接入的证明。构建和类型检查的通过也不等同于全流程浏览器测试。
