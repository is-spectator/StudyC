## 执行与记录约定

1. **先复用，后生成。** 所有主路径使用 S、M、F；不再次上传同一资料、不重复创建测试集。先检查生成进度／列表，若已有相同任务产物就继续它，不重复点击创建。优先完成不耗生成额度的阅读、复习、配置和恢复检查。
2. 新产物统一命名 `功能测试 · <用例ID> · 线段计数`，记录可见 URL／ID、源材料、配置、开始与终止时间。每个需要生成的主路径最多先做一个最小可用任务；显示付费或限额时记录门槛，不自动购买、不改套餐、不反复尝试绕过。
3. 下表“通过标准”是未来判断规则。结果填写“通过／未通过／额度或套餐阻塞／权限阻塞／访问阻塞／当前版本未见入口／待执行”，并保留实际截图或可见文本。**门槛提示被正确观察不等于生成或学习功能通过。** 没有入口时记录位置与账户条件，不断言所有账户不支持。
4. 比较前后状态时区分完成率、正确率、信心、掌握度、覆盖率和到期数；记录 UI 原名与实际分母，不合并为一个“进度”。长任务离开再回来仅重开同一任务，不重复提交。
5. 本计划只允许在隔离对象中留测试内容；不删除 S、M、F，不重置整账户学习历史，不修改真实姓名、邮箱、订阅或原有日程。涉及公开发布、发送邮件／iMessage、连接第三方账户、付费、真实设备媒体权限的项目须具备相应授权与条件；不具备时只记录入口或保持未测。
6. 全部判断来自可见 UI、正常打开的链接和生成文件；不读取 Cookie、令牌、数据库、隐藏客户端状态或非公开接口。访客检查使用独立未登录浏览器环境，不退出当前主账户。

续测优先次序：确认会话及已有对象 → 复核题量/类型、掌握提示和匹配计数差异 → 补 SRS 其他评级/到期、收藏取消与保存 → 引用精准定位和续做/持久化 → 在现有媒体与应用上补播放、反馈和恢复边界。已经完成的生成主路径不因下表保留原步骤而再次创建；额外上传、付费或外部授权项保持相应阻塞或待授权状态。

## 留给下一位执行者的结果记录格式

每次补测或回归后另存实际证据，并追加到详细审计/实测 CSV；不覆盖旧证据。推荐名称 `case-<ID>-<状态>-<序号>.txt/png`；只写必要页面内容，避免账户资料、可用私有分享凭据与完整个人录音。可使用下表作为单条测试记录：

| 字段 | 填写要求 |
| --- | --- |
| 用例／执行时间 | 用例ID、实际日期时间、时区；未执行不要填完成时间。 |
| 对象／前置条件 | 学习集、材料、产物的可见ID或链接；当前套餐与相关剩余额度，未显示则写未显示。 |
| 实际输入／配置 | 来源、语言、题数／时长、类型、插件、权限选择。 |
| 操作与结果 | 实际做了哪些步骤、在哪一步终止；原样记录重要提示，区分创建、生成、播放／作答、保存。 |
| 判定与限制 | 通过／未通过／阻塞／未见入口；只覆盖实际执行范围，未来 SRS 到期或跨设备测试单独列待办。 |
| 证据／清理 | 对应截图、可见文本、生成文件；是否恢复测试高亮／主题／日程等临时修改，核心 S/M/F 保留供后续复用。 |

**本文件保留回归步骤，不声明全部用例待执行或全部通过。** 已有结果见顶部续接对照及最新审计/实测 CSV；下一次先复用对象，针对剩余边界执行并留证。
