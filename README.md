# StudyC · 你的学习空间

前端 React + TypeScript + Vite，独立后端 Hono + PostgreSQL。以实际浏览器采集的 StudyFetch 页面、原站公开字体和插画为视觉依据，将资料整理、理解和练习整合为一个学习空间。当前正式账户使用云端学习集和纯文本资料；旧引导与内置学科示例仅保留在开发预览中，不作为云端学习数据。

## PR-005～007 本地验收

```sh
npm ci
(cd server && pnpm install --frozen-lockfile)
npm run local:acceptance -- --planplan-config /绝对路径/PlanPlan的私密OpenRouter.env
```

打开 `http://127.0.0.1:5180/`，点击「进入验收账户 A」，在「水循环与城市」内查看资料问答、闪卡、测验与考试。「进入验收账户 B」用于检查账户隔离。独立 PGlite 数据保存在忽略目录 `.local/acceptance`，重启后保留；Ctrl-C 停止服务。此入口仅绑定回环地址，使用合成身份，不连接生产数据库或发送注册邮件。

模型继续使用 PlanPlan 原 OpenRouter 配置。2026-11-23 初验遇到 429；随后保持原模型完成真实问答、闪卡与测验生成，实测结果见[本地验收记录](docs/acceptance-pr005-007.md)。问答成功补验包含 GitHub #8 的兼容修复。免费模型仍可能限流，失败时明确提示，不自动切换模型。独立 `automated-qa` 与测试上游只用于受控回归，与上述真实调用分开记录。

## 启动

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5178
```

开发服务器和 `vite preview` 将 `/v1/study/` 转发到本机独立 StudyC 8790，其他 `/v1` 转发到现有账户服务 8789；需自行启动受控联调服务。代理不会放宽 Cookie、Origin 或 CSRF。本仓库不启动 PlanPlan 服务。生产静态页使用 Nginx 同源代理，不需要在前端填写服务器密钥或数据库连接串。

仅查看本地界面时，可以在开发模式显式进入预览，或运行：

```sh
VITE_AUTH_MODE=preview npm run dev
```

预览能力只在 Vite 开发模式开放。生产构建及其 `vite preview` **必须验证账户**，不会因设置预览环境变量而绕过登录。会话无法验证时，学习界面会被锁定，重新验证后才能继续；资料请求的网络错误或服务端 5xx 本身不会清除账户身份，错误和未保存内容保留在当前界面。

构建、类型检查与离线测试：

```sh
npm run build
npm test
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s deploy/tests -p 'test_*.py' -v
```

正式账户入口：`/platform/studysets`。学习集使用 `/platform/studyset/:studySetId`，文本资料使用 `/platform/studyset/:studySetId/material/:materialId`，新建资料为同级 `/material/new`。旧 `/platform`、`/platform/onboarding`、`/platform/studyset/main` 入口均回到学习集列表，不自动绑定某个云端学习集。

## 云端学习空间（PR-002）

| 功能 | 当前实现 |
| --- | --- |
| 学习集 | 创建、列表分页、搜索已加载的学习集、改名；同名集合以不同 UUID 区分。 |
| 纯文本资料 | 按学习集列出、创建、打开、编辑和保存标题与正文；显示读取、未保存、保存中、已保存和失败状态。 |
| 保存与冲突 | 创建请求保留幂等 ID 供结果不明时重试；编辑使用版本检查，冲突保留本机输入并提供服务器版本供用户决定。 |
| 草稿与离开页面 | 按当前账户和资料保留未同步草稿；离开编辑页面前确认。草稿保存在本机，不等于云端已保存。 |
| 本机旧数据 | `/platform/local-data` 只读查看和 JSON 导出当前账户的旧记录、未同步草稿与待确认请求；导出保留原始内容，包括无法解析的记录。 |

学习集和已成功保存的文本资料由独立 StudyC 后端存入 PostgreSQL，以账户和学习集 ID 隔离。同一账户重新登录或换设备后从服务器读取；未保存草稿、待确认请求和旧版记录仍在当前浏览器。云端请求失败不会静默改存本机并显示保存成功。旧匿名数据与开发预览数据不会自动导入正式账户，旧资料也不会按名称自动归入云端学习集；暂不提供备份导入。

本分支的问答、闪卡和测验已接入独立后端；学习计划等后续工具继续显示“尚未开放”。生产需另外发布这些 PR 才会开放新功能。

## 仅开发预览的旧页面与示例

以下功能由 `LegacyApp` 承载，只有显式开发预览会加载。它们使用预览账户下的 localStorage 或页面内存，不接入云端学习集，也不代表正式账户已开放相应服务。

| 页面组 | 当前实现 |
| --- | --- |
| 引导、主页、学习集、学习计划 | 学习目标选择，学习集建立/改名/搜索/排序，文件夹归属，示例资料，计划完成标记，专注计时 |
| 资料库、笔记、阅读、日历 | TXT/Markdown 导入，笔记编辑，资料查找，内置长文阅读，日/周/月视图与学习安排 |
| 闪卡、测验、考试、知识点题库 | 卡片创建与复习，有限内置题目的答题、判分、解析和记录，按学段与学科选择练习 |
| 聊天、小C辅导 | 小C 聊天界面及服务状态说明，预设知识点题目、提示和逐步解析 |
| 课堂录音、音频复习 | 浏览器录音/回放/下载、手动课堂笔记；朗读配置、速度选择与浏览器语音朗读 |
| 互动练习、学习工具 | 知识配对游戏、示例搜索/排序、本地游戏配置；工具收藏与快捷入口 |
| 作业批改、视频讲解 | 作业文本保存与结构统计、图片预览；讲解提纲保存、查看与文本下载 |
| 设置、会员方案 | 本地头像/名字/用户名/可选学习阶段，学习用量、已存学习数据导出；StudyC进阶版／StudyC全能版选择与演示结账说明 |

认证凭据使用服务端设置的 HttpOnly Cookie，前端不把密码或令牌写入 localStorage。两个子域各有独立的 host Cookie，默认分别登录；退出或重置密码遵循现有 PlanPlan 账户的跨设备失效规则。注册继续受现有邮箱邀请名单限制。

开发预览的音频和游戏配置各保留最近一份。课堂录音仅保存在当前页面内存中，离开页面或刷新前需下载；课堂文字笔记可以本地保存。录音需要浏览器支持并获得麦克风授权，朗读使用设备可用的浏览器语音；本机数据导出不包含这类临时录音。

## 未接入的服务

PR-004～007 提供 OpenRouter 生成任务、带来源问答、资料闪卡和单选/判断测验。游戏自动生成、作业 AI 批改、语音辅导、录音转写、视频生成、支付、第三方集成、推送和学习资料自动导入尚未接入。登录后的云端学习集可以上传文本型 PDF，提取文字并保留页码；扫描件、加密件和损坏文件会标明失败，不会显示成已解析。Word 与图片 OCR 未实现。开发预览仍使用本地示例。

开发预览的题库是有限的基础学科示例，不是完整课程题库，也没有原版护理题库的专家审核或题量承诺。学习工具与互动练习展示本地功能，不包含真实社区作者、点赞数据或 3D 游戏服务。预览中的会员价格仅用于还原参考页面，选择方案不会创建订单或扣款。
