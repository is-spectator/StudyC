# StudyC · 你的学习空间

前端 React + TypeScript + Vite，独立后端 Hono + PostgreSQL。以实际浏览器采集的 StudyFetch 页面、原站公开字体和插画为视觉依据，保留已观察到的页面结构与流程，将资料整理、理解和练习整合为一个学习空间。引导按课程学习、考试准备和自主探索选择目标，学习阶段可选；现有内置示例仍以基础学科知识为主。

当前归档 **34 张原站参考截图**，覆盖主要入口、列表空态、创建首步和部分弹窗。它们不代表原站所有页面与状态；本项目也不宣称全站逐页像素级复刻。

**2026-11-20 统一注册已上线：[Clyna 首页](https://clyna.ai) · [StudyC](https://study.clyna.ai) · [PlanPlan](https://planplan.clyna.ai)。** 两个产品的注册入口都前往 Clyna 首页，使用既有受邀邮箱注册服务和账户数据库；注册成功后选择产品登录。StudyC 保留原登录和密码重置，未增加跨子域免登。Study 静态产物为 `8e77afb6…350371`，部署与回滚信息见[部署记录](deploy/README.md)。

注册表单由 Clyna 首页统一承载，StudyC 接入已有登录、密码重置、会话校验和退出接口。本轮 StudyC 生产构建及 23 项认证/会话/存储测试、5 项主站入口单测、19 项部署测试通过。隔离的本地模拟服务验证了错误验证码、注册成功、注册已接受后会话暂不可用的状态，以及 390px 表单布局。线上三个域名的 HTML/资源与构建匹配；两个注册按钮均实际跳转至主站，匿名认证接口为 401 且不缓存。未创建生产测试账户或执行真实邮件注册/重置验收。

首次双域发布已确认两个新域名的 HTTP 跳转到各自 HTTPS，证书有效期至 2027-02-17，既有自动续期任务包含新证书且模拟续期通过。首次发布沿用了这些配置；当前后端状态以 [2026-11-21 独立服务发布记录](deploy/release-20261121-independent-backend.md) 为准。

## 启动

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5178
```

开发服务器和 `vite preview` 将 `/v1/study/` 转发到本机独立 StudyC 8790，其他 `/v1` 转发到现有账户服务 8789；需自行启动受控联调服务。代理不会放宽 Cookie、Origin 或 CSRF。本仓库不启动 PlanPlan 服务。生产静态页使用 Nginx 同源代理，不需要在前端填写服务器密钥或数据库连接串。

仅查看本地界面时，可以在开发模式显式进入预览，或运行：

```sh
VITE_AUTH_MODE=preview npm run dev
```

预览能力只在 Vite 开发模式开放。生产构建及其 `vite preview` **必须验证账户**，不会因设置预览环境变量而绕过登录。会话无法验证或网络断开时，学习界面会被锁定，重新验证后才能继续。

构建、类型检查与离线测试：

```sh
npm run build
node --test src/auth/api.test.mjs src/auth/session-state.test.mjs tests/account-storage.test.mjs
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s deploy/tests -p 'test_*.py' -v
```

入口：`/platform/onboarding?currentStep=studying`。学习首页：`/platform/studyset/main`；全局主页：`/platform`。

## 页面与本地功能

| 页面组 | 当前实现 |
| --- | --- |
| 引导、主页、学习集、学习计划 | 学习目标选择，学习集建立/改名/搜索/排序，文件夹归属，示例资料，计划完成标记，专注计时 |
| 资料库、笔记、阅读、日历 | TXT/Markdown 导入，笔记编辑，资料查找，内置长文阅读，日/周/月视图与学习安排 |
| 闪卡、测验、考试、知识点题库 | 卡片创建与复习，有限内置题目的答题、判分、解析和记录，按学段与学科选择练习 |
| 聊天、小C辅导 | 小C 聊天界面及服务状态说明，预设知识点题目、提示和逐步解析 |
| 课堂录音、音频复习 | 浏览器录音/回放/下载、手动课堂笔记；朗读配置、速度选择与浏览器语音朗读 |
| 互动练习、学习工具 | 知识配对游戏、示例搜索/排序、本地游戏配置；工具收藏与快捷入口 |
| 作业批改、视频讲解 | 作业文本保存与结构统计、图片预览；讲解提纲保存、查看与文本下载 |
| 设置、会员方案 | 本地头像/名字/用户名/可选学习阶段，学习用量、已存学习数据导出；StudyC进阶版／StudyC全能版选择与演示结账说明 |

StudyC 的学习资料与练习记录仍保存在当前浏览器的 localStorage，按服务端验证的账户 ID 分开存储；开发预览独立存储，旧匿名数据不会自动导入登录账户。共用注册账户不等于学习资料已上传到 PlanPlan，也不提供跨设备学习数据同步。设置页仅导出当前账户已保存的学习数据；导出不含录音等临时内容，暂不支持备份导入。

认证凭据使用服务端设置的 HttpOnly Cookie，前端不把密码或令牌写入 localStorage。两个子域各有独立的 host Cookie，默认分别登录；退出或重置密码遵循现有 PlanPlan 账户的跨设备失效规则。注册继续受现有邮箱邀请名单限制。

音频和游戏配置各保留最近一份。课堂录音仅保存在当前页面内存中，离开页面或刷新前需下载；课堂文字笔记可以本地保存。录音需要浏览器支持并获得麦克风授权，朗读使用设备可用的浏览器语音。

## 未接入的服务

AI 对话、自动从资料生成卡片/试题/游戏、作业 AI 批改、语音辅导、录音转写、视频生成、支付、第三方集成、推送和学习资料自动导入尚未接入。PDF/Word 解析与图片 OCR 也未实现。相关流程使用本地示例或说明当前限制，不应将原版功能名称理解为服务已经上线。

题库是有限的基础学科示例，不是完整课程题库，也没有原版护理题库的专家审核或题量承诺。学习工具与互动练习展示本地功能，不包含真实社区作者、点赞数据或 3D 游戏服务。会员价格仅用于还原参考页面，选择方案不会创建订单或扣款。
