# PR-009：错题本与独立重练

日期：2026-11-24。仓库 `is-spectator/StudyC`，分支 `codex/studyc-mistake-review`。基于 PR-008 的已验收分支继续开发，新增迁移 v8；全部业务代码位于 StudyC。生产发布单独进行。

## 用户结果

学习集侧栏「错题」汇总已提交练习/考试中的真实错误；原测验成绩页「查看本次错题」仅筛选该次提交。用户可以查看原始错答、正确答案、解释与来源快照，再选择同一测验的 1–20 题独立重练。重练逐题自动保存、显示反馈，支持刷新或从记录续做，提交后分别显示首次正确率和最终得分。

入口：`/platform/studyset/:setId/mistakes`。可选查询参数 `quizId`、`fromAttempt`（须有 quizId）、`mistakeReview`；参数为真实 UUID，重复或非法参数显示错误并提供返回全部错题入口。原作答链接 `/practice?quizId=...&attemptId=...` 现在恢复指定试卷与尝试，不任意打开第一份记录。

## 统计与数据口径

- 仅收集整轮已提交的原始练习/考试；每题首次保存的选择错误，或交卷时最终选择错误，即归入错题。中途曾错但首次与最终都正确不纳入本版本规则。
- 每个 `(attemptId,questionIndex)` 至多一条事实，按 `(userId,quizId,questionIndex)` 汇总。题干相同但测验不同不合并。一次提交中改答多次不增加原错误次数；重复交卷、回填不双计。
- 列表分别显示当前筛选内的原错误次数、首次错误数、最终错误数；选择本次尝试筛选时只统计这次提交。原始记录保留每次来源和答案，最多20条一页，可继续读取。
- 未提交的考试与练习都不会进入错题列表/详情/重练来源；请求未提交 attempt 筛选返回404。原站已存在的同一测验历史答案不构成监考隔离，本产品仍是个人自学。
- 重练采用独立 ID、快照、选择和事件，原成绩不变。首次答案与后来的修改分别保存；分母始终是本轮实际题数，最后一题也计入。
- 重练题序为原 questionIndex 升序；API 作答中的 questionIndex 指本轮位置，返回的 originalQuestionIndex 用于追溯原题。不能由客户端提交题目、正确答案、来源或分数。
- 重练结果不进入原错误次数，只显示最近一次已提交重练的正误。一次答对不标为永久掌握。跨测验拼卷、收藏/高亮、AI出新题、自适应难度不包含在本包。

## 数据、升级与回填

v8 新增三表，不修改 v1～v7 的 SQL、checksum、约束或索引：

| 表 | 作用 |
| --- | --- |
| `study_mistake_facts` | 原始已提交错题事实，主键为 attemptId/questionIndex，保存首次/最终答案与正误、题目、来源快照及提交时间。 |
| `study_mistake_reviews` | 独立重练的固定题目集合、原题/尝试映射、首次及最终选择、版本、状态与时间；同账户开始请求 ID 唯一。 |
| `study_mistake_review_events` | 每次选择/提交的请求摘要与内容，同账户请求 ID 唯一，每轮只允许一个提交事件。 |

原测验提交与错题归档在同一事务中；失败不会留下“提交成功但未归档”的状态。历史回填使用与新提交相同的查询及唯一键，迁移首次自动回填，跳过已注销账户；原有试卷、尝试、分数与迁移记录保持一致。

维护命令：在与现有服务相同的受控运行环境中执行 `node dist/main.js backfill-mistakes`（先执行 migrate）。继续使用既有 `STUDYC_SECRETS_FILE`、`PG_CA_FILE`、`STUDYC_FILE_ROOT`、`RELEASE_ID` 配置与 TLS 校验；命令不读取模型凭据、不启动HTTP或worker，只输出插入行数，重复执行不会重复计数。它不提供公网 HTTP 入口。

写入继续使用 active-user 守卫，外键绑定账户、学习集、原测验/尝试；账户硬删除级联清理新增记录，业务请求先核验当前账户。重练写入按账户串行，并通过版本号与请求摘要防止丢失更新和重复提交。

`STUDYC_MISTAKES_ENABLED=false` 可关闭新重练的开始、答题和提交；已有错题/成绩仍可查看，原测验仍能正常提交并保留事实。关闭后页面提示状态并禁用写入按钮。回退使用仍识别 v8 的应用，保留表与记录；不能直接把旧 v7 应用连到 v8 登记的库。

## API 契约

前缀 `/v1/study/sets/:setId`，同源 Cookie、Expected-User、Origin/CSRF、共享写限流、private/no-store；写入 JSON 上限16KiB。部署代理增加6组精确路径、7种方法组合，其他产品代理不改变。

| 路径 | 方法 | 行为 |
| --- | --- | --- |
| `/mistakes` | GET | 分页汇总；可筛 quizId/已提交 attemptId，limit 1–50；cursor 为所属 quizId:questionIndex。 |
| `/mistakes/:quizId/:questionIndex` | GET | 原始错答及来源，20条一页；cursor 为同一错题的原 attemptId。 |
| `/mistake-reviews` | GET/POST | 分页历史 / `{clientRequestId,quizId,questionIndices}` 新建固定重练。 |
| `/mistake-reviews/:reviewId` | GET | 恢复进度或查看独立成绩。 |
| `/mistake-reviews/:reviewId/answers` | POST | `{clientRequestId,version,questionIndex,answerIndex}` 保存选择，未答题不提前返回反馈。 |
| `/mistake-reviews/:reviewId/submit` | POST | `{clientRequestId,version}` 全部作答后提交，只计分一次。 |

新建/新事件返回201，原请求重放200；同请求ID改内容409，版本冲突409，未完成提交400，未归属对象404，错误方法405，超请求体413。结果不明确时前端保留同一请求体供用户重试；409可重新读取云端进度。切换账户/学习集取消请求，迟到响应不回填新页面。
