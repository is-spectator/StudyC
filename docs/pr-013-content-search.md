# PR-013：当前已保存学习内容的账户内搜索

2026-11-24。分支 `codex/studyc-content-search`，基于 PR-012 的日边界审查修复 `65b93a2`。StudyC 独立业务，无新表或新迁移，不修改已有数据；仅本地部署。

## 用户结果与搜索口径

全局侧栏「搜索学习内容」→输入关键词→选择类型/学习集→点击搜索→打开准确对象。支持中文及普通拉丁字母大小写匹配。空词显示引导，无匹配时说明可缩短关键词/扩大范围；条件保留在URL，刷新和浏览器返回可恢复。

| 类型 | 检索范围 | 打开位置 |
| --- | --- | --- |
| 学习集 | 当前名称 | 对应学习集UUID。 |
| 资料 | 当前标题、当前纯文本正文 | 对应资料编辑页。已提取PDF正文视作资料；未提取成功的原文件不伪装成可搜资料。 |
| 笔记 | 已明确保存后的当前标题、当前编辑稿 | notes?noteId=实际UUID，不搜索原稿、引用快照或未保存候选。 |
| 闪卡组 | 当前组名、当前卡片正反面 | flashcards?flashcardDeck=实际UUID，多张卡命中仍只一条组结果。 |
| 测验 | 名称、题干 | practice?quizId=实际UUID，多个题干命中仍一份测验。 |

不检索测验选项、答案、正确答案索引、解析、引用、未提交作答、私有作答快照、历史稿、生成任务或聊天记录。计划、日历、旧浏览器数据和未导入文件也不属于本版搜索。搜索不会推断掌握度或修改学习记录。

不同学习集内的同名对象保持不同ID和来源名称，结果链接必须与类型/所属集/对象ID一致；前端拒绝外部链接或与实体不匹配的地址。摘要作为React普通文本渲染，HTML/脚本不能执行。

## 查询、分页与数据边界

`GET /v1/study/search?q=...&type=all&studySetId=...&limit=20&cursor=...`。q去首尾空白后1～120个UTF-16单元，控制符/无效代理字符拒绝。按字面子串匹配，`%`、`_`、引号和反斜杠没有通配或SQL意义。type为all/study_set/material/note/deck/quiz，studySetId可选但必须归当前账户。limit为1～50，默认20。

服务端始终绑定当前认证账户。各表通过owner和学习集复合关系过滤；来源标题来自同账户的当前学习集。每个返回对象仅包含类型、ID、所属集ID/名称、当前标题、至多240个Unicode字符的匹配附近片段及本站准确路径。没有全库计数，也不返回完整原始正文或私有试题结构。

结果按类型和UUID稳定排序，游标绑定账户、规范化关键词、类型和学习集筛选及完整排序键；修改筛选/账户、伪造格式、命中对象已不可用时需重新搜索。游标只是位置，不是权限凭证。每次查询不使用OFFSET；卡片/题干通过侧向查询只取首个匹配，避免多次命中放大结果或拼接整套卡片。

本版为账户内字面查找，没有中文分词、模糊排序或全文索引。沿用既有owner/学习集索引，生产查询设置事务内3秒statement_timeout；超时明确要求缩小范围，不在全库无限扫描或假报无结果。大规模数据的相关性搜索和专用文本索引需要独立性能验收。

API沿用同源Cookie、Expected-User、private/no-store及认证边界，只开放GET；Nginx新增一条精确只读路径，其他产品代理保持不变。`STUDYC_SEARCH_ENABLED=false`停止新搜索，既有学习对象保持原状；关闭后不会用浏览器旧内容假装返回服务端结果。
