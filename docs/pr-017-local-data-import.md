# PR-017：明确预览与归属的旧本机文本导入

「本机旧数据」→「导入旧文本资料」，可预览当前验证账户的本机记录，或选择该账户以前导出的 StudyC v1 JSON。只读取文件/预览不发送正文；先下载或保留原始 JSON 备份，勾选支持项、明确选择云端目标学习集并确认上传。本机原记录永不删除、修改或静默认领，不能按课程/姓名猜测归属。

本版只支持真实旧版 `sf-k12:uploads` 中 `{title,text}` 的文本。损坏条目逐项报告原因及原位置；只有名称的旧学习集、题目/卡片/成绩/计划、未同步草稿与待确认请求等均标为不支持，保留在完整原始备份。不会把旧本机练习成绩变成新的服务端学习记录。标题规范化去首尾空白，正文完整保留（1MiB/项）。HTML 只作文字展示。

导出格式要求 `format=studyc-local-data-export`、version=1、accountId=当前认证账户；不允许匿名键或其他账户记录。rawEntries 与 entries 并存时检查两者一致，损坏/冲突明确标出而不悄悄选一份。最多5MiB导出、1000个键/1000条上传资料；预览正文只显示前2000字符，导入使用完整文本。超限明确拒绝并保留原文件。新文件损坏或账户不符时清空旧预览，不能误提交上一份文件。文件读取使用账户会话 fence，切换账户后的旧读取不能写入新账户。

API：GET `/v1/study/imports/status` 返回开关；POST `/v1/study/imports` 载荷 `{clientRequestId,sourceAccountId,targetSetId,items:[{sourceKey:'sf-k12:uploads',sourceIndex,title,body}]}`，最多100项/实际JSON2MiB。只发送勾选的合格文本，不发送整份导出中的设置/其他记录。服务端独立校验字段、账户、正文、目标有效性及重复源位置，原子提交，不依赖浏览器判断。沿用同源认证、Expected-User/Origin/CSRF、写限流和严格代理方法；其他产品不变。

迁移v15新增 `study_import_requests` 与 `study_import_items`。同账户组织锁内创建资料并登记来源指纹/原位置/目标ID。指纹由认证账户、来源键、原数组位置和规范化标题/完整正文计算，与导出时间无关。相同旧记录再次导入同一目标返回 already_imported 和原材料ID，保留导入后云端编辑；不同原位置即使同文仍是不同记录。明确导入到另一学习集或旧原文确有变化是新的导入，保留原映射。

同一请求响应丢失时冻结表单并重试原意图，不重建资料；同ID改载荷409。返回逐项 imported/already_imported 与实际ID，供核对。目标进入回收站时拒绝新导入与回放，不自动恢复。`STUDYC_IMPORT_ENABLED=false` 保留本地预览、备份和已导入内容，拒绝上传；回退保留v15表，使用识别v15的应用。

真实 Chrome/Playwright（Browser plugin not available）账户A验收：预览无上传；2项支持/1项损坏/2项不支持；下载JSON与输入文件逐字相同；成功201后丢弃响应并同请求重试只创建2份；再次导入显示0新建/2已存在，且保留云端独立编辑；损坏或其他账户文件不保留可提交的旧预览；桌面1440×1000、手机390×844无运行错误和横向溢出。验收数据保留「本机资料导入 · 验收 …」，原始合成备份、截图与脚本位于 `/tmp/studyc-pr017`，不入库。

服务端专项覆盖指纹/请求幂等、云端编辑保留、不同位置同文、源变化、明确目标、跨账户、回收站、坏项原子拒绝、v14升级、开关、账户删除级联和HTTP边界；前端专项覆盖实际旧格式、逐项状态、损坏原始条目、一致性、账户隔离、HTML文本和限额。全量回归与前后端构建通过后提交。
