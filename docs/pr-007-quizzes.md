# PR-007：资料测验、练习与考试

本地实现，尚未部署。依赖统一生成服务的 `quiz` 类型及迁移 4–6，前端入口为 `QuizzesPanel`。测验只使用当前账户同一学习集选择的 1–5 份资料及明确版本；生成结果必须经过服务端结构与引用验证，再幂等保存为测验。

从学习集侧栏或工具区的“测验与考试”进入 `/platform/studyset/:setId/practice`。刷新后重新选择已保存测验，可从作答记录继续。资料列表支持继续加载，生成时固定使用勾选资料的版本。

## 用户流程

选择资料、语言及题量后生成。单选与判断各 0–10 题，总数 1–20。题量和来源在任务提交时固定；资料后来修改不改变题目与原引用。生成失败保留任务状态，页面不会伪造题目或自动重复调用模型。

练习与考试是独立作答记录。选择一个选项即保存，成功提示“答案已保存”；发生连接问题可重试同一次请求，也可重新读取服务器记录。刷新或离开后，从测验的作答记录继续。

- 练习：每次选择后显示该题正误、正确答案、解析及引用。可以改答，历史不会覆盖；未答题不提前显示答案。
- 考试：保存选项，整份提交前不返回正误、答案、解析或引用。必须回答所有题目才可提交。提交仅计分一次，提交后的答案不能再编辑。
- 成绩分别展示首次作答正确率与最终得分。首次指每题第一次保存的选择；最终指交卷时最后保存的选择，均以全部题目数为分母，包含最后一道题。
- 引用显示资料标题、原版本和可确认页码；可展开提交时的原文快照。当前资料版本不同会明确标注。

这是自学测验，并非监考或防作弊系统：同一所有者可以另开练习获得反馈。考试接口本身及通用生成接口不会直接返回未提交考试的答案键。

## 接口与持久化

接口共用 StudyC Cookie、Expected-User、Origin、CSRF 和 `private, no-store`。POST JSON 上限 16 KiB；严格拒绝调用者传入题目、正确答案或成绩。

| 方法 | 学习集内路径 | 输入/结果 |
| --- | --- | --- |
| GET / POST | `/quizzes` | 分页列表 / `{generationId,clientRequestId}` 保存已成功生成任务 |
| GET | `/quizzes/:quizId` | 题目和选项，无答案键 |
| GET / POST | `/quizzes/:quizId/attempts` | 历史分页 / `{mode,clientRequestId}` 新作答 |
| GET | `/quizzes/:quizId/attempts/:attemptId` | 恢复进度或查看已提交成绩 |
| POST | `/quizzes/:quizId/attempts/:attemptId/answers` | `{questionIndex,answerIndex,version,clientRequestId}` 保存选择 |
| POST | `/quizzes/:quizId/attempts/:attemptId/submit` | `{version,clientRequestId}` 提交整份 |

完整前缀为 `/v1/study/sets/:setId`。列表默认 20 条、最多 50 条，游标限定同一账户与集合/测验。资料、生成任务、测验与作答记录全链路核对归属。

Nginx 白名单新增 6 组测验路径、8 种方法组合，全部 StudyC 业务接口合计 31 组路径、42 种方法组合。测验沿用 16 KiB 上限、同源与禁止缓存设置，未知路径与非法 UUID 不代理。

迁移 6 新增 `study_quizzes`、`study_quiz_materializations`、`study_quiz_attempts` 和 `study_quiz_events`。物化登记表绑定每个请求 ID 与原任务，包括不同入口重复保存同一生成任务的请求；改用该 ID 保存另一任务会返回 409。测验保存题目及来源快照；每次作答再次保存独立题目快照，无编辑这些快照的 API。选项保存和交卷在账户级数据库事务锁中进行，版本冲突返回 409；事件保存请求摘要，重放同一请求不重复增加记录，相同请求 ID 改内容返回 409。交卷事件有唯一约束，账户注销级联清理私有记录。

## 验证

`server/test/quizzes.test.ts` 使用隔离 PGlite、合成账户与可控 OpenRouter 响应，实际经过生成结果验证后保存测验，覆盖考试答案隐藏、练习改答历史、最后一题计分、首次/最终成绩、幂等、版本冲突、并发交卷、续答、来源旧版本、账户隔离和 HTTP 认证边界。

`src/study/quizzes/api.test.mjs` 验证误泄露考试答案时拒绝响应、账户/集合切换后的迟到响应失效、写入不自动重试及提交后复盘。真实模型质量与浏览器交互验收另行记录；当前实现没有访问外部 AI 或服务器。
