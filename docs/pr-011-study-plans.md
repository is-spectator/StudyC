# PR-011：学习目标与手动计划

2026-11-24，StudyC 独立前后端，分支 `codex/studyc-study-plans`，基线为 PR-010（GitHub #11）。仅本地部署；不自动合并或发布生产。

## 用户流程与完成口径

学习集侧栏「学习计划」→新建计划（名称、目标说明、目标日期）→添加任务（名称、日期、可选关联资料/闪卡/测验/笔记）→打开真实活动→手动完成或明确关联已完成记录。日期为公历 `YYYY-MM-DD`，不表示某个时刻，不随账户/服务器时区换日。空日期允许，非法日期拒绝。

- 计划目标与任务分开建模；每项任务有稳定 UUID。关联对象必须属于同一账户、同一学习集，任务保留关联名称快照。关联创建后固定，重新生成不会悄悄改绑；需要换对象时取消旧任务并新建。
- 任务支持改名、改期、手动完成、撤销手动完成、取消和恢复。手动标记保存操作者及时间，不宣称由系统验证了学习效果。
- 系统依据单独保存，只有用户明确选择真实学习记录后关联。可以关联任务创建后开始、已完成的自由闪卡学习、至少评价过一张卡的已结束间隔复习，或已整轮提交的练习/考试。仅打开活动、答了部分题或全部跳过过期卡都不够。
- 任务创建时间比较在数据库中保留微秒精度，不能用 JS Date 截断后误纳入更早的学习。资料和笔记没有阅读完成记录，因此只提供手动标记。
- 撤销手动完成不会删除系统依据。取消任务保留历史，不允许继续完成或关联记录；恢复后可继续。一个完成记录在同一任务内不会重复计数。系统依据只是完成一轮活动的事实，不是永久掌握证明。
- 系统依据选择器显示最近50条合格记录。列表每页20，支持继续加载。原测验成绩、自评和 SRS 调度不被计划改写。

## 数据、幂等与恢复

迁移 v10 `studyc_study_plans` 新增 `study_plans`、`study_plan_tasks`、`study_plan_evidence`、`study_planning_requests`。仅新增独立表，不改 v1～v9 SQL/checksum/fingerprint。复合外键绑定任务的计划、账户及学习集；有效账户写守卫和账户删除级联清理保留。

全部写操作带 `clientRequestId`；修改另带预期 `version`。同账户按事务锁串行；相同请求重试不重复建立实体或重放状态变化，同ID改变载荷409。已确认过的旧请求重试返回实体当前状态，不能把后来撤销的任务重新标为完成。

版本冲突409保留本地输入，同时显示云端目标/任务；用户比较后读入新版本，再明确保存。结果不明确时保留同一次请求供重试；刷新可重新读取已保存对象。未保存输入通过刷新/导航确认保护，不承诺崩溃恢复。导航守卫现在可同时保护多个任务编辑框，未编辑的其他任务不能盖掉已有守卫。

全量回归发现既有闪卡自评在相同时钟时间可能按随机UUID取错“最近一次”。现有自评事务锁内保存严格递增的微秒时间，仍使用原表，不改历史迁移；回归覆盖相同时刻/时钟回退后的实际顺序。

关闭 `STUDYC_PLANS_ENABLED=false` 后可查看目标、任务及历史依据，拒绝新建、修改和关联。回退须使用仍识别v10的应用并保留表，不把v9应用直接接入v10库。

## API

前缀 `/v1/study/sets/:setId`；同源 Cookie、Expected-User、Origin/CSRF、private/no-store及共享限流；写入 JSON 上限16KiB。新增6组精确Nginx路径、10种方法组合，Clyna/PlanPlan代理不变。

| 路径 | 方法 | 行为 |
| --- | --- | --- |
| `/plans` | GET/POST | 20条分页 / `{clientRequestId,title,goal,dueDate}` 创建。 |
| `/plans/:planId` | GET/PATCH | 读目标 / `{clientRequestId,version,title,goal,dueDate}` 编辑。 |
| `/plans/:planId/tasks` | GET/POST | 20条分页 / `{clientRequestId,title,dueDate,activity}` 添加。activity为null或 `{kind,id}`。 |
| `/plans/:planId/tasks/:taskId` | PATCH | `{clientRequestId,version,title?,dueDate?,manualCompleted?,cancelled?}`，至少一项。 |
| `/plans/:planId/tasks/:taskId/evidence` | GET/POST | 合格完成记录 / `{clientRequestId,version,sessionKind,sessionId}` 关联，完成时间由服务端原记录给出。 |
| `/planning-options` | GET | type为material/deck/quiz/note，20条分页；只返回该集当前账户对象ID/名称。 |
