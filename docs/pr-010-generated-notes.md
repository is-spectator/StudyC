# PR-010：资料生成笔记

日期：2026-11-24。业务代码全部在 StudyC；分支 `codex/studyc-generated-notes`，以 PR-009 分支 `codex/studyc-mistake-review` 为增量基线。本次仅部署本地，生产发布单独处理。

## 用户结果与范围

入口 `/platform/studyset/:setId/notes`，学习集侧栏「笔记」。用户从当前集选择 1–5 份文本资料（含已提取成功的 PDF 文本），选择中文或英文及 1–8 个章节，创建生成任务。生成成功后先预览候选正文和每章原文引用，点击「保存为笔记」才建立独立笔记。

保存后可重新打开、编辑标题与正文；支持简单 Markdown 的标题、段落、无序/有序列表和引用。React 只渲染文本节点，HTML、脚本、图片及链接语法作为普通文本，不执行内容或自动请求远程图片。不是完整 Markdown 或富文本编辑器。

原始生成稿、原资料版本与快照独立于当前编辑稿保留。手动编辑后显示「原引用尚未对编辑后的内容重新验证」。重新生成须返回列表创建新候选，不覆盖已有笔记。OCR、插图、朗读、阅读进度、协作、自动保存、编辑历史回退均不在本包；尚未保存的编辑通过离开/刷新确认保护，未承诺崩溃恢复。

## 生成及保存契约

- 新生成类型 `study_note`，提示版本 `study-note-v1`；配置严格为 `{language,sectionCount}`。复用既有任务、输入快照、用量预留、取消、明确重试与最多三次尝试。没有自动重试、模型降级或替代。
- 输出包含 title 和固定数量 sections，每章 heading/body/citations。标题最多160字符，章标题120，正文4000，合计生成稿还须符合保存正文64KiB UTF-8上限；每章1–3条引文，至少12个非空白字符，必须在指定原文中唯一连续匹配。服务端计算资料ID、版本、偏移和PDF页码，不接收模型虚构位置。
- 模型任务成功不自动保存。保存请求只接受 jobId/clientRequestId，必须属于当前账户和学习集、类型正确、状态成功；保存前重新检查原资料哈希、结构和引用位置。客户端不能提交生成稿、来源或版本冒充模型结果。
- 同账户同请求ID改意图409；相同意图重放返回同一笔记。对同一生成任务使用另一个请求ID也返回同一笔记，不建立副本。笔记、原稿与保存意图同事务提交。
- 当前笔记修改用乐观版本锁。409时保留输入、读取最新云端内容并同时展示；用户选择保留自己的内容或采用云端内容，之后再明确保存。PATCH响应丢失也按此规则核对版本，不静默覆盖。
- 同一生成任务的笔记编辑后再保存原候选仍返回该笔记当前内容，不重置已编辑正文。新候选拥有独立任务ID。

## 数据与迁移

v9 `studyc_generated_notes`：新增 `study_notes`（当前稿、版本、编辑标志）、`study_note_origins`（唯一生成任务、原始结果及来源快照）、`study_note_materializations`（保存请求摘要）；扩展 generation kind 约束允许 study_note。外键绑定所属用户与学习集，写入使用有效账户守卫；来源到生成任务的约束延迟到事务结束检查，允许账户级联清理全部从属数据，同时阻止孤立删除仍被笔记引用的任务。账户硬删除回归通过。

不修改 v1～v8 SQL、checksum、登记时间或历史 fingerprint。本地验收过程中修正本PR尚未发布的v9外键：先备份完整本地库，保留所有笔记和v1～v8登记后同步v9约束/校验，正式仓库仅包含最终v9定义。v4 检查在存在 v9 表时只把 kind 约束投影回历史四种类型；v9 单独 fingerprint 完整生成表实际结构，扩展约束被篡改仍能检测到。已有 v6/v7 升级测试先还原真正的旧结构再验证升级；额外验证 v8→v9、重复 migrate/check、旧登记和内容保留、kind 漂移拒绝。

生产升级必须停止旧 StudyC 进程、执行 migrate、启动识别v9的应用。保留数据回退时使用仍识别v9的版本，不能把只识别v8的进程直接接到v9库。

`STUDYC_NOTES_ENABLED=false` 关闭新笔记生成、任务重试、候选保存和笔记编辑；保存稿、原稿及来源仍可查看，现有任务仍可取消。关闭不清表，不中断已运行的模型请求，也不回收已经发生的用量。

## API 与代理

同源 Cookie、Expected-User、Origin/CSRF、private/no-store 和既有共享限流继续生效。新增两组 Nginx 精确路径/四种方法，不改变 Clyna/PlanPlan 代理。JSON请求体上限256KiB，笔记正文另限64KiB UTF-8（JSON转义开销单独容纳）。

| 路径（学习集前缀 `/v1/study/sets/:setId`） | 方法 | 行为 |
| --- | --- | --- |
| `/notes` | GET | 按创建时间/UUID降序，每页20；cursor为该账户该集笔记ID，返回功能状态。 |
| `/notes` | POST | `{clientRequestId,jobId}` 显式保存，首次201/重放200。 |
| `/notes/:noteId` | GET | 当前笔记与原始结果、原资料快照。 |
| `/notes/:noteId` | PATCH | `{version,title,body}` 修改当前稿，版本加一。 |
| `/generations` | POST | `kind:study_note`、原资料ID/版本、language/sectionCount；其余任务接口复用。 |

跨账户/跨集对象404，版本或意图冲突409，错误方法405，过大请求413，关闭功能503。列表与详情可刷新恢复；最近生成记录显示通用任务列表最近50条中的笔记任务。
