# PR-016：当前纯文本资料的真实复制

从学习集「复制学习内容」或已保存资料的「复制这份文本资料」进入预览，勾选当前文本，明确选择新建学习集或已有目标。新建学习集只含选中资料，也允许明确创建空副本。不会把只列出的一部分资料声称为整个学习集完整复制。

第一版只复制当前纯文本资料的标题和正文（包括已保存的 PDF 提取文本），不复制原 PDF 字节、AI 笔记、闪卡、测验、来源引用、成绩、学习记录、计划、日程或文件夹归类。副本和新学习集使用新 UUID、资料版本从 1 开始，能独立编辑。来源映射包含原资料 ID/版本/标题正文摘要哈希及新 ID，不把旧学习历史伪装成副本自己的历史。

迁移 v14 增加 `study_copy_requests`，复合外键限定来源/目标均归同账户。复制是一个原子事务：同账户组织写锁，检查源/目标学习集有效、来源集与每份资料版本；最多100份、正文合计10MiB。任何版本冲突、跨账户或不可用来源都不产生部分副本。预览最多100份并明确 hasMore，可从单份资料入口访问其余项。客户端不拿到预览正文。

GET `/v1/study/sets/:setId/copy-preview?materialId=可选UUID`；POST `/v1/study/copies`，载荷 `{clientRequestId,sourceSetId,sourceVersion,materials:[{id,version}],target:{kind:'new_set',title}|{kind:'existing_set',id}}`。命令32KiB，同源 Cookie/Expected-User/Origin/CSRF、写限流、只允许对应方法。请求回放返回原映射，不创建第二份；目标后来进入回收站时旧请求不能复活或重建副本。

来源版本变化时表单保留并提示重新预览，需重新核对。响应丢失或上游5xx时冻结编辑和普通提交，只能核对同一次请求。账户切换与离开作用域中止后续更新。`STUDYC_COPY_ENABLED=false` 保留来源预览，拒绝复制；回退保留 v14 表，使用仍识别该迁移的应用。其他产品代理不变。
