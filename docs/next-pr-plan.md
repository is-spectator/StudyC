## PR-009 的范围与验收线

实现与接口、迁移和验收见 [PR-009 任务书](pr-009-mistake-review.md)。

**入口**：学习集侧栏「错题」，以及已提交测验的结果页「查看本次错题」。

1. 默认收集已提交练习/考试中「本次尝试第一答错误，或提交时最终错误」的题。同一题以 `(userId, quizId, questionIndex)` 汇总；原错误次数按已提交的 `(attemptId, questionIndex)` 每次至多计一次，尝试内多次改答、重复交卷及历史回填不能重复增加。重练成绩单独记录，不混入原错误次数。不同测验中题干相同不按文本擅自合并。
2. 未提交考试不得借错题列表、计数、搜索或重练入口泄露答案及正误；练习也统一在整轮提交后归入错题本，避免两套不一致的收集口径。
3. 修改成正确答案不会抹去首次错误。页面能分辨「首次答错、后来改对」「最终仍错」，并打开当时题目、解释和资料快照。
4. 用户选择同一测验的错题开始一轮独立重练；首版每轮最多 20 题，顺序固定，保存实际题目集合和逐题选择，提交后展示首次正确率/最终得分并支持历史续做。跨测验拼卷留后续。
5. 用独立作答 ID 与错误集合键关联原题；原尝试、原分数保持不可变。同一请求重放只产生一轮，同一提交不重复计入统计。一次正确不标为「永久掌握」，只显示最近重练结果。
6. MVP 以错题事实与重练为中心；收藏任意题、高亮原文、多色标注、题目导出、自适应难度分别另拆。

**验收样例**：两题先错后改对并提交，错题本有两条；同一题第二次错答仍是一条但来源增加；考试未交卷前无泄露；重练两题只对一题得到 50%，原考试分数不变；B 对 A 的错题与重练均 404。为既有已提交记录提供可重复运行的回填，并通过唯一键防止新提交与回填双计。

## PR-010 的范围与验收线

**入口**：学习集「笔记」，从当前学习集选择 1–5 份已就绪资料生成。

1. 复用 PR-004 的任务、取消/明确重试、用量及输入版本约定。新增独立生成类型和严格输出结构，不把聊天文本直接当作已保存笔记。
2. 每份笔记包含标题、正文段落及段落引用；生成后预览，用户明确保存。初版支持 Markdown 标题、列表、普通文本与引用，不引入任意 HTML、脚本、协作编辑或块编辑器平台。
3. 生成结果与用户编辑分开记录；编辑后保留生成出处，并明确其未重新验证。重新生成创建新候选，不覆盖已经编辑的笔记。
4. 笔记有独立 UUID、所属学习集、版本及可打开的历史来源；正文修改使用现有 409 处理方式。源资料变更不会改写旧笔记与引用快照。
5. 只用已确认可用的原 OpenRouter 配置；真实调用遇到 429 明确显示失败，不自动改模型或重复扣额。

**验收样例**：两份内容明显不同的资料生成不同笔记；引用来自所选资料；保存响应丢失不会产生两份；编辑冲突不丢草稿；旧来源 v1 与现资料 v2 分开显示；刷新与另一浏览器恢复；B 无权限读取。独立阅读进度、朗读、插图、OCR 与富文本历史回退不包含在本包。
