## 环境与证据口径

真实 Hono API、生成 worker、资料引用校验、Cookie/CSRF、持久 PGlite、React 界面全部运行在本机。浏览器使用已安装 Chrome（Playwright 驱动），桌面 1440×1000、手机 390×844。

成功生成的自动化验收使用独立 `.local/automated-qa` 数据目录与临时可控 OpenRouter HTTP 上游。它提供 JSON/SSE 数据，再经过产品的真实解析器、任务状态、数据库及引用验证。测试内容明确标记 QA，不能证明原模型内容质量或目前可用性。该传输模块和合成配置仅在临时目录，未进入产品构建、PR 或用户验收环境。

交付的 `.local/acceptance` 使用 PlanPlan 原 OpenRouter 配置 `baidu/ernie-5.5-flash-preview:free`。用户明确选择保留原模型；初验实际调用返回过 `provider_rate_limited`（429）及 `invalid_response`；直接诊断确认过 Baidu 共享免费池返回 `tpm_rate_limit_exceeded`。这些失败均未算作有效回答，没有切换付费模型或伪造成功回答。两套数据互不混用。其后独立复测已取得真实成功结果，并定位、修复问答的解析问题，见末节。
