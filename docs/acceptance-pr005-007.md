## 浏览器实际操作

| 场景 | 观察结果 |
| --- | --- |
| 登录与资料问答 | 进入账户A真实学习集，选择资料并发送；逐步显示后才出现已核验引用；引用弹窗定位原文，刷新保留对话 |
| 手动闪卡 | 新建卡组、添加两张卡；翻面自评后服务端推进；第1张保存后刷新续学；最后一张保存后显示完成，累计2条自评 |
| 资料生成闪卡 | 选择资料、生成2张、预览后明确保存为卡组，可展开原版本引用 |
| 409编辑冲突 | 同时显示本地草稿与云端v2；点击保留输入不会自动覆盖，再次明确保存才更新为v3 |
| 保存成功但响应丢失 | 服务端201后中断响应；相同请求ID重试200、同cardId、数据库仅一张卡 |
| 跨卡组迟到响应 | A开始学习已保存但响应延迟，切回列表进入B；释放A响应不污染B，B使用独立请求ID开始成功 |
| 练习模式 | 两题中第1题先错再改对，第2题答对；即时解析、改答历史可见；交卷首次正确率50%，最终得分100% |
| 考试模式 | 提交前无正确答案或解析；答1题后刷新，通过测验历史恢复第2题；全部提交后得分100%，结果包含最后一题 |
| 账户隔离 | 账户B仅见自己的学习集；请求账户A的闪卡返回404 |
| 桌面与手机 | 三个模块都有实际内容，无横向溢出；页面无运行时异常或意外控制台错误；未出现开发错误遮罩 |
