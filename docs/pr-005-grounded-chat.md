# PR-005：基于资料的问答与来源

StudyC 的学习集新增「资料问答」。选择当前学习集的 1–5 份资料，建立对话并向小C提问；每轮保存问题、资料版本、原文快照和生成任务。回答使用真实上游流式增量，最终结构和引用核验通过后才显示为有效回答。

## 行为与边界

- 对话历史按账户、学习集隔离；刷新或重新登录后可以继续查看。每个学习集最多 100 段对话，每段最多 100 轮。
- 每轮问题最多 2,000 字符，选中资料正文合计最多 32 KiB。后续编辑资料不会修改已保存问答的输入、引用或页码。
- 服务端仅从已经成功保存的回答提取最近四轮上下文，并限制上下文字节数；浏览器不能提交伪造历史或系统提示词。
- 一段对话同时只允许一个未结束的生成尝试。停止会中断上游，明确重试沿用旧输入；已发生的用量不因停止而清零。重试仅适用于最后一轮，次数沿用 PR-004 限制。
- 显示中的流式内容标记「生成中，引用待核验」。坏 JSON、无法定位的引用、上游失败和中断均不当作成功；资料不足是单独的有效回答状态。
- 点击引用打开当时的原文快照并突出引用区间；同时提供当前资料入口，二者版本明确区分。原始 PDF 的引用可以显示页码。

## 接口

基路径为 `/v1/study/sets/:setId/chat/threads`，继续使用既有 Cookie、Expected-User、Origin 与 CSRF。

| 方法 | 后缀 | 内容 |
| --- | --- | --- |
| GET / POST | 空 | 对话列表 / 幂等创建 |
| GET | `/:threadId` | 对话与全部已保存轮次 |
| POST | `/:threadId/messages` | 问题、资料 ID/版本、语言及请求 ID |
| POST | `/:threadId/messages/:turnId/stop` | 明确停止 |
| POST | `/:threadId/messages/:turnId/retry` | 使用新请求 ID 明确重试 |
| GET | `/:threadId/messages/:turnId/events` | 受保护的 SSE 进度、任务状态与结束事件 |

事件包含 attemptId；刷新或重连回放当前尝试的已保存进度。断开 SSE 不会取消后端任务，停止必须调用写接口。流连接有时间、用户和进程数量上限。前端逐事件检查当前账户，旧账户的迟到事件不能更新新账户页面。

## 迁移与生成基础

迁移 v4 追加对话、轮次、持久进度表，并扩展生成任务种类。v1–v3 的 SQL、checksum 和历史记录保留；v3 使用明确的历史约束投影核验，v4 另外核验扩展后的生成约束。轮次问题和生成关联不可修改，账户删除级联清理。

生成协议同时准备好后续闪卡和测验的结构校验；产品牌组、学习事件和测验记录在 PR-006 / PR-007 交付。OpenRouter 模型和凭据继续沿用批准的 PlanPlan 配置。

## 本地验收

```sh
npm ci
cd server
pnpm install --frozen-lockfile
cd ..
npm run local:acceptance -- --planplan-config /绝对路径/PlanPlan的私密OpenRouter.env
```

访问 `http://127.0.0.1:5180/`，点击「进入验收账户 A」。账户 A 含两份独立主题的合成资料，账户 B 用于核验隔离。数据保存在本仓库忽略的 `.local/acceptance`，重启保留数据；会话重启后重新登录。Ctrl-C 停止本地前后端。

本地入口只绑定回环地址，使用独立合成身份和持久 PGlite，不接触生产账户、数据库或邮件。凭据仅从指定的受限文件读入进程内存；验收脚本被排除在生产构建之外。正式认证中间件不放宽 Cookie、Origin 或 CSRF。

2026-11-23 真实模型调用仍返回 Baidu 上游 429。用户选择保留原模型，未切换供应方或付费模型。自动测试的可控上游成功路径与真实调用结果分别记录；模型限流恢复前，不能把成功生成视作已完成真人验收。代码和本地服务不代表生产发布。
