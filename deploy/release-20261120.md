## 代理与数据范围

Study 仅代理 7 个精确认证路由：GET `/v1/auth/web/session`、GET `/v1/me`、POST `/v1/logout`，以及 POST `/v1/auth/web/email/{code,register,login,reset}`。其他 `/v1` 请求拒绝，响应不缓存。Host、Origin 和认证请求头保留；前端没有数据库或模型密钥。

PlanPlan 新别名保持原应用的 API 范围。两个子域共用账户记录，但使用各自 host 的 HttpOnly Cookie，因此默认分别登录；不是跨域单点免登。注册白名单与全账户退出/重置规则沿用现有服务。
